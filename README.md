## Как залить на GitHub

> ⚠️ Заливайте в **отдельный репозиторий** (например, `klt-civ-solo-demo`), а не в репозиторий основного сайта —
> иначе демо-данные заменят настоящие CSV.

1. GitHub → **New repository** → имя, например `klt-civ-solo-demo` → **Public** → *Create repository*.
2. На странице репозитория: **Add file → Upload files** → перетащите **всё содержимое** этой папки
   (`index.html`, три файла данных и папку `img`) → *Commit changes*.
3. **Settings → Pages** → *Source: Deploy from a branch* → ветка `main`, папка `/ (root)` → *Save*.
4. Через 1–2 минуты сайт откроется по адресу `https://<ваш-логин>.github.io/klt-civ-solo-demo/`.

## Как считается

«Качество игры» (0–100) считается тем же алгоритмом, что и дашборд логов: средневзвешенная оценка шести
направлений — экономика, развитие колоний, экспансия, военное дело, отношения с племенами, отцы-основатели.
Пока революция не объявлена, итоговая оценка партии в дашборде ограничена 38/100 — поэтому на сайте
основной показатель — качество игры, а итоговая оценка показана отдельно.

Блок информационный: **баллы рейтинга КЛТ не меняются** — за Civilization Solo они, как и раньше,
начисляются только за защиту революции. Если файла `civ_solo_logs.json` нет, сайт работает как обычно,
просто без этого блока.
